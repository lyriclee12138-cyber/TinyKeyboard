中文 / base64 解码

HID 只能敲英文，中文会先编成 base64。电脑端用 decode.py 还原，只用到 Python 自带的 base64 和 sys，不装任何库。

① 手机点「发送」把 base64 敲进电脑，另存为 b64.txt。
② 点上面按钮把 5 行代码敲进记事本，另存为 decode.py（和 txt 放一起）。
③ 命令行运行 python decode.py b64.txt → 生成 decoded.txt。
